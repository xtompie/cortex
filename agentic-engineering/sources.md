# Agentic engineering — gdzie szukać

## Oficjalne źródła
- [Claude Code docs](https://code.claude.com/docs) — best practices, memory, skills, subagents, output styles; tabela „What you can stop doing” pokazuje przestarzałe rady
- [Anthropic Engineering](https://www.anthropic.com/engineering) — context engineering, harnessy dla długich zadań, systemy wieloagentowe
- [platform.claude.com — Prompting Claude X](https://platform.claude.com/docs/en/build-with-claude/prompt-engineering/claude-prompting-best-practices) — każdy nowy model zmienia gadatliwość i narrację
- [Codex docs i guides (OpenAI)](https://learn.chatgpt.com/guides/best-practices) — AGENTS.md, skille, subagenty, ewaluacja skilli
- [agents.md](https://agents.md/) i [agentskills.io](https://agentskills.io/) — otwarte standardy plików instrukcji i skilli
- [anthropics/skills](https://github.com/anthropics/skills) — wzorcowe skille i `skill-creator`

- [Jesse Vincent — blog.fsck.com](https://blog.fsck.com/) — Superpowers, testowanie skilli
