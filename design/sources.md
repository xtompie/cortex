# Design — gdzie szukać

## Anthropic i Claude
- [anthropics/skills](https://github.com/anthropics/skills) — oficjalne skille `frontend-design`, `canvas-design`, `brand-guidelines`; historia commitów pokazuje zmiany wytycznych
- [Claude Cookbook](https://platform.claude.com/cookbook) — oficjalne przepisy na prompty, w tym frontend aesthetics
- [claude.com/resources/articles](https://claude.com/resources/articles) — artykuły zespołu Applied AI z Anthropic
- [Anthropic News](https://www.anthropic.com/news) — premiery produktów, np. Claude Design
- [rohitg00/awesome-claude-design](https://github.com/rohitg00/awesome-claude-design) — pliki DESIGN.md według estetyki, opinie o Claude Design

## Skille do designu
- [skills.sh — topic Design & UI](https://skills.sh/topic/design) — ranking skilli do designu według instalacji; `/trending` pokazuje nowości z 24h
- [vercel-labs/web-interface-guidelines](https://github.com/vercel-labs/web-interface-guidelines) — aktualne reguły audytu UI od Vercel
- [pbakaus/impeccable](https://github.com/pbakaus/impeccable) — pełny proces designu, rubryka krytyki, lista odmowy (`reference/`)
- [leonxlnx/taste-skill](https://github.com/leonxlnx/taste-skill) — kierunek artystyczny z badania 247 stron, rubryka zrzutów (`references/`)
- [emilkowalski/skills](https://github.com/emilkowalski/skills) — ruch i detale interfejsu od autora Sonnera
- [nextlevelbuilder/ui-ux-pro-max-skill](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill) — baza stylów, palet, par fontów i zasad UX

## SVG
- [arXiv cs.CV, szukaj „text-to-SVG”](https://arxiv.org/list/cs.CV/recent) — nowe prace o generowaniu SVG przez LLM co miesiąc
- [Simon Willison — pelican-riding-a-bicycle](https://simonwillison.net/tags/pelican-riding-a-bicycle/) — szybki test SVG każdego nowego modelu
- [Chat2SVG](https://chat2svg.github.io/) — pełne prompty w aneksie
- [StarVector](https://github.com/joanrod/star-vector) — główny otwarty model SVG
- [SVGO](https://github.com/svg/svgo) — optymalizacja SVG, zmiany wersji
- [TPGi — SVG accessibility](https://www.tpgi.com/using-aria-enhance-svg-accessibility/) — wzorce dostępności SVG
- [svg.dog/learn](https://svg.dog/learn/) — praktyczne poradniki: animacja, SVGO
